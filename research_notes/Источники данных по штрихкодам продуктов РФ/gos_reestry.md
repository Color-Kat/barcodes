## 1. Национальный каталог товаров (ЦРПТ): маршруты доступа в 2026, кто может получить ключ, лимиты, цена, условия, атрибуты состава/КБЖУ, публичная страница по GTIN

### Takeaway
API-ключ Нацкаталога выдаётся только внутри личного кабинета «Честного знака», вход в который возможен по УКЭП юрлица или ИП; физлицо и самозанятый (не ИП) зарегистрироваться не могут, а «технологический партнёр» тоже регистрируется от имени гендиректора или ИП и проходит модерацию ЦРПТ. Карточки продуктов питания реально содержат «Состав» и (для части категорий) блок КБЖУ, а публичный сайт каталога — это ограниченная витрина без рабочего поиска и с запретом в robots.txt.

### Cited Findings
**Доступ и ключ**
- Документация API НК актуальна: версия 5.68 от 28.09.2026. Адреса: продуктив `апи.национальный-каталог.рф`, тест `api.nk.sandbox.crptech.ru`. Авторизация — `apikey` либо токен ГИС МТ (`Authorization: Bearer`), токен получают через True API (единая аутентификация) — [docs.crpt.ru, API НК](https://docs.crpt.ru/gismt/API_НК/)
- Ключ берётся в ЛК НК: «Профиль» → «Данные участника», поле «API KEY»; поле видно только пользователю с ролью «Администратор» — [docs.crpt.ru, API НК, п. 2.2](https://docs.crpt.ru/gismt/API_НК/)
- Чтобы увидеть ключ, нужно войти в ЛК системы маркировки (`markirovka.crpt.ru/login-kep`, тестовый `markirovka.sandbox.crptech.ru/login-kep`) с УКЭП; ключ показывается только руководителю/администратору — [markirovka.ru, «Как получить party_id/API Key…»](https://markirovka.ru/knowledge/tovarnye-gruppy/obschie-voprosy-gis/kak-poluchit-party-id-api-key-klyuch-dostupa-v-natsionalnom-kataloge); то же в пересказе, «проверено 15.09.2026 по базе знаний ЧЗ от 28.07.2026» — [selsup.ru](https://selsup.ru/blog/kak-poluchit-party-id-api-key-nacionalnogo-kataloga/)
- Самозанятый / физлицо: «Физическое лицо, не зарегистрированное в качестве индивидуального предпринимателя, не является участником оборота товаров и не может быть зарегистрировано в системе маркировки Честный Знак»; участники оборота по ПП РФ от 31.05.2025 № 819 — юрлица, ИП и филиалы иностранных юрлиц — [markirovka.ru, «Могут ли зарегистрироваться… самозанятые (не ИП)»](https://markirovka.ru/knowledge/tovarnye-gruppy/detskie-igrushki/mogut-li-zaregistrirovatsya-v-gis-mt-samozanyatye-ne-ip)
- Технологический партнёр: регистрация через «Реестр партнеров и интеграторов» (`registry.intuot.crpt.ru/byteam/portal/index.html`); указывается тип участника (технологический партнёр или участник оборота), данные компании; «если регистрация происходит первый раз, её должен проводить генеральный директор организации или индивидуальный предприниматель»; заявку одобряют модераторы ЦРПТ, логин/пароль приходят на почту — [markirovka.ru, «Как технологическому партнёру зарегистрироваться…»](https://markirovka.ru/knowledge/developers/become-technology-partner/kak-tekhnologicheskomu-partnyeru-zaregistrirovatsya-v-lichnom-kabinete). Один из комментаторов статьи пишет, что заявки отклоняют «без причин и объяснений» (частное мнение, не официальная позиция) — там же.
- В документации НК есть роль «Интегратор/Разработчик ПО», выбираемая «при регистрации доступа к API Национального каталога»; только ей доступен метод `/v3/short-product` (краткая/полная информация о карточке, включая `good_images` и `good_attrs`) — [docs.crpt.ru, API НК, п. 3.1.3](https://docs.crpt.ru/gismt/API_НК/)
- Позиция поддержки по «API для личного использования»: «политика системы такова, что документацию можно посмотреть только в личном кабинете продуктивного контура или в реестре интеграторов. Поэтому в открытом доступе такая информация не хранится» — [markirovka.ru, «Спросите у эксперта»](https://markirovka.ru/community/ask-expert/kak-poluchit-dostup-k-api-chestnogo-znaka-dlya-lichnogo-ispolzovaniya)
- Живая проверка: без ключа и продуктив, и песочница отвечают `HTTP 401` с пустым телом (`GET /v3/product?gtin=4601576000027`) — [апи.национальный-каталог.рф](https://апи.национальный-каталог.рф/v3/product?gtin=4601576000027), [api.nk.sandbox.crptech.ru](https://api.nk.sandbox.crptech.ru/v3/product?gtin=4601576000027). Сторонний проект в июле 2026 фиксировал «HTTP 501 без ключа; ключ платный, по договору» — [EatBefore, docs/CATALOG.md](https://github.com/Lucky2356/EatBefore/blob/HEAD/docs/CATALOG.md); код ответа с моим результатом расходится, утверждение о платности первоисточником не подтверждено.

**Лимиты**
- Лимит персональный на организацию: общий (пример заголовка `API-Usage-Limit: 1/500`) и частный на метод (`API-Method-Usage-Limit: 1/10`); «при исчерпании лимита запросов начать новую серию можно через пять минут с момента отправки первого запроса»; при превышении `429` + `Retry-After`; ответ `304 Not Modified` по ETag лимит не расходует — [docs.crpt.ru, API НК, п. 2.1, 2.4, 2.5](https://docs.crpt.ru/gismt/API_НК/)
- Метод `/v3/product`: «возвращает информацию по опубликованным и архивным карточкам товаров», частный лимит «100 запросов в серии», до 25 позиций в `gtins`/`good_ids` за запрос — [docs.crpt.ru, API НК, п. 3.1.2](https://docs.crpt.ru/gismt/API_НК/)
- Поправка к известному команде: `/v4/product-list` возвращает только «список товаров, принадлежащих владельцу», максимум 10 000 позиций в выборке, `limit` до 1000 — для обхода чужих карточек не годится — [docs.crpt.ru, API НК, п. 3.1.4](https://docs.crpt.ru/gismt/API_НК/)

**Глубина данных (состав, КБЖУ, фото) — по живым карточкам НК, полученным через мобильный API (см. раздел 2)**
- Атрибут «Состав» (`attr_id` 2483, группа «Состав») заполнен во всех 8 из 8 опубликованных продовольственных карточек из тестовой выборки — [mobile.api.crpt.ru/mobile/check, проба 13.10.2026](https://mobile.api.crpt.ru/mobile/check)
- Группа атрибутов «Энергетическая ценность, белки, жиры и углеводы» («Белки, количество», «Жиры, количество», «Углеводы, количество», «Энергетическая ценность, ккал», единицы «г/100г», «ккал/100г», флаг «Наличие требований к указанию пищевой ценности») есть в 4 из 8: майонез, кетчуп, кондитерская плитка, колбаса. Нет в молоке и твороге (там только «Жирность, %»), в минеральной воде; у сока есть только «Количество углеводов, г/100 мл» — там же
- Фото (`good_images[].photo_url`, хост `национальный-каталог.рф/s3/med/…jpg`) есть в 2 из 8 карточек; файл отдаётся анонимно (`HTTP 200`, `image/jpeg`, 63 КБ) — [пример фото](https://национальный-каталог.рф/s3/med/6593a0cfea367e3de41199234c550c80.jpg)

### Inferences
- Единственный реалистичный официальный маршрут к API НК — ИП или ООО с УКЭП, зарегистрированные в «Честном знаке» как участник оборота либо как технологический партнёр; самозанятому и физлицу путь закрыт.
- Теоретическая пропускная способность `/v3/product` при лимите 100 запросов × 25 GTIN за 5-минутную серию — порядка 2 500 GTIN за серию, то есть до ~720 тыс. GTIN в сутки на одну организацию; 1,35 млн штрихкодов проходятся примерно за двое суток. Это расчёт по примерам из документации: фактический лимит «персональный» и может отличаться.
- Публичный сайт показывает лишь часть карточек (вероятно, с отдельным признаком публикации на витрине): карточки со статусом `published` в API на сайте дают 404. Как источник для массового сбора он не подходит и из-за `Disallow: /`.
- Блок КБЖУ в НК, судя по выборке, обязателен не для всех товарных групп: он есть в бакалее/кондитерке/мясе и отсутствует в молочке и воде.

### Gaps
- Общее число карточек в НК и число продовольственных карточек с заполненным составом: официальной цифры не нашёл (поиск выдаёт только инструкции). Счётчик 134 331 относится к публичной витрине, а не ко всему каталогу.
- Выдаётся ли продуктивный apikey НК технологическому партнёру (роль «Интегратор/Разработчик ПО») без собственной маркируемой продукции и какой у него лимит — не проверено; уточнять в support@national-catalog.ru.
- Лицензионные условия переиспользования данных НК в стороннем потребительском приложении (оферта/пользовательское соглашение НК) — документ не найден.
- Перечень обязательных атрибутов по категориям (`/v3/attributes?cat_id=…`) без ключа недоступен — частота заполнения оценена только по 8 карточкам.
- Утверждение о новых правилах регистрации в ЧЗ с 01.03.2026 (отказ при отсутствии уведомления в реестре Роспотребнадзора) видел только в поисковой выдаче, первоисточник не открывал — не проверено.

## 3. GS1 RUS: GS46, Verified by GS1, GEPIR — что возвращает поиск по российскому GTIN, API, цена, есть ли состав

### Takeaway
GS1 RUS закрыл GEPIR и заменил его сервисом Verified by GS1 (search.gs1ru.org): он отдаёт только базовую идентификацию товара (бренд, описание, вес, категория GPC, одно изображение, владелец префикса), без состава и КБЖУ, и стоит за Yandex SmartCaptcha. Пакетные запросы и API доступны только членам ассоциации через кабинет Rich; каталог ГС46 — за авторизацией.

### Cited Findings
- «Вместо сервиса GEPIR предлагаем вам сервис Verified by GS1 для верификации данных по идентификационным ключам GTIN, GLN и др., также поиск по названию компании, номеру ИНН» — [gs1ru.org/services/vbg](https://gs1ru.org/services/vbg/); `gepir.gs1ru.org` отвечает редиректом `308` на `search.gs1ru.org` — живая проверка, [gepir.gs1ru.org](https://gepir.gs1ru.org/)
- Публичный поиск — SPA; запрос идёт `POST https://be-rich.gs1ru.org/api/v3.2.0/gtin-search/public` с телом `{gtin, captcha_token}`, токен выдаёт Yandex SmartCaptcha (`smartcaptcha.yandexcloud.net`) — код фронтенда, [search.gs1ru.org/assets/index-a4dbc417.js](https://search.gs1ru.org/assets/index-a4dbc417.js). Сам запрос не выполнял (капча).
- Поля результата в коде фронтенда: `gtin`, `brandName` («Товарный знак»), `productDescription` («Описание»), `productImageUrl` («Изображение»), `gpcCategoryCode` («Категория GPC»), `netContent` («Количество/вес»), `countryOfSaleCode` («Рынок сбыта»), `dateUpdated`, `licenseInfo` (компания: название, ИНН, GLN, адрес, сайт), `isComplete`, `linkset` — там же
- Баннер в интерфейсе: «Хотите выполнять проверки по нескольким GTIN, GLN или другим ключам за раз? Воспользуйтесь Rich… пакетные запросы и подключение к API. Вступите в ассоциацию ГС1 Рус…» (ссылка `rich.gs1ru.org/gtin-search/search`) — там же
- Взносы ГС1 РУС: вступительный 25 000 руб., ежегодный 15 000 руб.; для участников программы обязательной маркировки — 3 000 и 3 000 руб.; взнос не возвращается — [gs1ru.org/join/membership](https://gs1ru.org/join/membership/). Льготный тариф 3 000 руб. закреплён соглашением ЦРПТ – НК – ГС1 РУС (2019) — [национальный-каталог.рф/page/about-partnership](https://национальный-каталог.рф/page/about-partnership)
- Каталог ГС46: на сайте есть только ссылка «Вход в каталог ГС46» → `srs.gs1ru.org/login` (нужна учётная запись члена) — [gs1ru.org/join/membership](https://gs1ru.org/join/membership/); домен `gs46.ru` с этой машины не открылся (тайм-аут напрямую, ошибка TLS через прокси).

### Inferences
- GS1 RUS полезен только для проверки принадлежности префикса и получения бренда/описания; для задачи «EAN → состав» бесполезен.
- Цена входа для стартапа без маркируемой продукции — 25 000 + 15 000 руб./год, и это даёт идентификационные поля, а не состав.

### Gaps
- Содержимое карточки в ГС46 (есть ли там состав) и условия/лимиты API Rich — не проверено (закрыто авторизацией).
- Глобальный Verified by GS1 (gs1.org) и его суточные лимиты не проверял.
- Реальный ответ `gtin-search/public` для российского GTIN не получен из-за капчи.

## 4. ВетИС / «Меркурий» (Россельхознадзор): реестр номенклатуры с GTIN — публичный доступ, API, открытые данные

### Takeaway
В справочнике номенклатуры ВетИС у позиции есть поле GTIN, но нет ни состава, ни пищевой ценности, а доступ к Ветис.API дают только хозяйствующим субъектам и ветслужбам по заявке на бланке организации. Для стороннего приложения источник закрыт и по содержанию малополезен.

### Cited Findings
- Ветис.API — шлюз для обмена «с учетными системами хозяйствующих субъектов и ветеринарных служб»; доступ в два этапа (тестовый, затем продуктивный контур), «предоставляется по заявкам хозяйствующих субъектов и органов государственной власти субъектов РФ в сфере ветеринарии»; заявка через форму `t2-aplms.vetrf.ru/pub/` с ИНН хозсубъекта и сканом заявления «на бланке организации за подписью руководителя… и печатью»; регистрация до 5 рабочих дней; переход на продуктив после апробации «не менее 10 рабочих дней в режиме реального производственного процесса» — [help.vetrf.ru, Ветис.API](https://help.vetrf.ru/wiki/Ветис.API)
- `ProductService` («Сервис получения сведений из справочников продукции и номенклатуры») имеет операции `GetProductItemList`, `GetProductItemByGuid`, `GetProductItemByUuid`, `GetProductItemChangesList` и др.; точка доступа `https://api.vetrf.ru/platform/services/2.1/ProductService` — [WSDL ProductService v2.1](http://api.vetrf.ru/schema/platform/services/2.1-RC-last/ProductService_v2.1_production.wsdl)
- Тип `ProductItem`: `globalID` (тип `GTINType`, «Global Trade Identification Number (GTIN) — уникальный идентификационный номер продукции производителя»), `name`, `code` (артикул), `productType`, `product`, `subProduct`, `correspondsToGost`, `gost`, `producer`, `tmOwner`, `producing`, `packaging`, `isPublic` («Позиция справочника доступна для просмотра другим участникам»). Полей состава или пищевой ценности нет — [XSD dictionary_v2.1](http://api.vetrf.ru/schema/platform/services/2.1-RC-last/dictionary_v2.1.xsd)
- В карточках НК у молочной продукции есть атрибуты «Тип продукции (ВетИС)», «Продукция (ВетИС)», «Вид продукции (ВетИС)», «Подлежит ветеринарному контролю (надзору)» — связка НК ↔ ВетИС уже сделана на стороне ЦРПТ — ответ для 4601662000016, [mobile.api.crpt.ru/mobile/check](https://mobile.api.crpt.ru/mobile/check)

### Inferences
- Даже при наличии доступа ВетИС дал бы только «GTIN → наименование, вид продукции, производитель, ГОСТ, фасовка» и только для подконтрольной ветнадзору продукции (мясо, рыба, молочка).

### Gaps
- Существование открытых выгрузок номенклатуры с GTIN на сайтах Россельхознадзора не проверял; в справке Ветис.API о них ничего нет.
- Объём справочника номенклатуры и доля позиций с заполненным GTIN — не проверено.

- Набор деклараций ФСА можно скачать целиком и использовать как вспомогательную связку GTIN → изготовитель/ИНН/ТН ВЭД/наименование, но GTIN в декларациях, скорее всего, заполнен редко (поле необязательное) — долю нужно измерять на самом архиве.
- Для алкоголя, БАД и детского питания ключом остаётся карточка НК: именно она связывает GTIN с кодом ЕГАИС, номером СГР и декларацией, а сами отраслевые реестры штрихкода не содержат (для СГР — предположение, поля не проверены).

### Gaps
- Поля реестра СГР на nsi.eaeunion.org (есть ли состав для БАД/детского питания, есть ли штрихкод) и способ массовой выгрузки — не проверено: API портала не установлен.
- Размер архива ФСА и доля записей с заполненным GTIN — не проверено (архив не скачивал, сервер не вернул `Content-Length`).
- Открытые данные ФСРАР (раздел «Открытые данные» на сайте есть) — содержание не смотрел.
- Поиск наборов на data.gov.ru по словам «штрихкод», «GTIN» не выполнен (нет документированного эндпоинта) — наличие таких наборов не подтверждено и не опровергнуто.

## 6. Что ещё официальное, не названное в задании

### Takeaway
Из неназванных источников практическую ценность показал только блок `roskachestvo` внутри ответа мобильного API «Честного знака» (готовая связка EAN → карточка Роскачества); зарубежные аналоги (ePASS в Беларуси, НКТ в Казахстане) существуют, но белорусский поиск закрыт капчей, а казахстанский не проверен.

### Cited Findings
- В ответе `mobile/check` для 3 из 12 тестовых EAN есть объект `roskachestvo` (`roskachestvo_id`, `product_link`, `total_rating`, `criteria_ratings[]`, `has_quality_mark`, `product_documents`), например для молока 4601662000016: `roskachestvo_id: 3677677`, `product_link: "goods/moloko-pitevoe-ultrapasterizovannoe-massovaya-dolya-zhira-3-5-parmalat/"`, `total_rating: 5` — [mobile.api.crpt.ru/mobile/check](https://mobile.api.crpt.ru/mobile/check). К rskrf.ru запросов не делал.
- ePASS — «Банк электронных паспортов товаров в Беларуси» (присвоение GTIN, GLN); в меню есть «Поиск товаров по GTIN», «Поиск товаров по наименованию», «Проверка наличия товаров по списку GTIN» — [epass.by](https://epass.by/). Страница поиска `/publicsearch/searchgtin` перенаправляет на `/publicsearch/captcha` (текстовая капча) — живая проверка, не обходил.
- Казахстанский «НКТ | Национальный каталог товаров» доступен как SPA на `nct.gov.kz` — [nct.gov.kz](https://nct.gov.kz/); содержимое не проверял.
- На сайте «Честного знака» перечислены продовольственные товарные группы с партнёрскими решениями: `beer`, `beverages`, `brdrinks`, `canned_food`, `caviar`, `dairy`, `dietarysup`, `grocery`, `meat`, `nonalcoholic_beer`, `oil`, `pet_food`, `sportpit`, `sweets`, `water` — то есть по этим группам карточки в НК обязаны существовать — [честныйзнак.рф/business/partners](https://честныйзнак.рф/business/partners/)

### Inferences
- Связку EAN → Роскачество выгоднее брать из ответа «Честного знака», чем сопоставлять по названиям при обходе rskrf.ru.
- Перечень маркируемых продовольственных групп объясняет состав находок: бакалея, кондитерка, молочка, вода, соки, мясо дали полные карточки, а замороженные полуфабрикаты и снеки — заглушки.

### Gaps
- Содержит ли ePASS состав и КБЖУ белорусских товаров — не проверено (капча).
- Бэкенд мобильного приложения Роскачества не исследовал: запросы к rskrf.ru запрещены заданием.
- ГИСП (каталог промышленной продукции Минпромторга), КТРУ ЕИС, ФГИС «Зерно» и др. не проверял: по назначению они не содержат потребительских штрихкодов с составом, но это не подтверждено проверкой.
