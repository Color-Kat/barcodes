# База штрихкодов российских товаров — источники и пайплайн

Цель: скан штрихкода → карточка товара (название, фото, состав, КБЖУ, объём) для анализа состава.

## Как это делает Мира (и как сделать тебе)

Ни у кого нет одного «открытого дампа всех российских штрихкодов». Рабочая схема — трёхслойная:

1. **Seed** — массовые базы «штрихкод → название» (миллионы записей, без состава).
2. **Enrichment** — по каждому GTIN тянуть карточку из Национального каталога + ритейлеров (фото, состав, КБЖУ).
3. **Crowdsourcing** — когда юзер сканирует неизвестный код, просить сфоткать этикетку → распознать → пополнить базу. Так база сходится к реальному покрытию 95%+ (у Миры первые месяцы тоже было «товар не найден» — их база выросла на юзерах).

## Источники (по приоритету)

### 1. Национальный каталог товаров (ЦРПТ / «Честный знак») — главный
Государственный каталог карточек: GTIN, название, бренд, фото, атрибуты (для многих категорий — состав). Покрывает все маркируемые категории (молочка, вода, напитки, БАДы, косметика, парфюм и т.д. — маркировка постоянно расширяется).

- Прод API: `https://апи.национальный-каталог.рф`
- Карточка по GTIN: `GET /v3/product?apikey=XXX&gtins=...` (отдаёт **опубликованные карточки любых товаров**, не только свои)
- Массово: `GET /v4/product-list` (до 10 000 позиций за выборку)
- Документация: https://docs.crpt.ru/gismt/API_НК/
- Ключ: регистрация в ЛК «Честного знака» (нужно ИП/юрлицо — для стартапа оформи) или запрос на support@national-catalog.ru. Есть песочница `api.nk.sandbox.crptech.ru`.
- Скрипт: `natcatalog_enrich.py` (запускать с российского IP).

Это легальный официальный канал — то, на чём почти наверняка сидит Мира.

### 2. Open Food Facts — еда с составом и КБЖУ, бесплатно
~35 000 российских продуктов: штрихкод, название, состав, КБЖУ, фото. Мало по покрытию, но это готовые полные карточки еды.

- Скрипт: `off_import.py` (тянет parquet-дамп с Hugging Face, фильтр по `en:russia`).
- ⚠️ Лицензия **ODbL**: обязательна атрибуция, и производная база данных должна распространяться по той же лицензии (share-alike). Использовать внутри сервиса можно, но прочитай условия: https://opendatacommons.org/licenses/odbl/

### 3. aioke / catalog.app — 1,8 млн штрихкодов бесплатно
Дамп «штрихкод → категория, бренд, название» рос. рынка 2021–2022. **Без еды, одежды, лекарств** — зато закрывает косметику, бытовую химию, товары для дома (для сканера косметики — прямо в тему).

- https://github.com/aioke/barcodes, https://catalog.app/public-opportunities/download-barcodes
- Статьи: https://habr.com/ru/articles/699606/, https://vc.ru/tribuna/540260
- У catalog.app есть платная полная база (70 млн товаров, 160 млн фото) — вариант «купить и не парсить».
- Скрипт: `aioke_import.py`.

### 4. Платные базы/API по штрихкоду (fallback для неизвестных кодов)
- **Rate&Goods B2B** — российский аналог твоей идеи, база 30+ млн товаров, по штрихкоду отдаёт название, фото, **состав, Е-добавки**, цены. B2B-доступ: регистрация на https://b2b.ratengoods.com/, покупка запросов на /terminal/add (~500 запросов за 400₽, есть бесплатный лимит с ограничением частоты). Самый близкий к цели платный источник по еде.
- **1С:Номенклатура** — эталонный каталог 6,8 млн карточек (штрихкоды, производитель, фото, характеристики), от ~834₽/мес через подписку 1С:ИТС. Состав/КБЖУ систематически не заполнены — годится как справочник, не как источник состава.
- **barcodes.olegon.ru** — краудсорс-база сообщества ритейл-автоматизации, миллионы российских EAN. API: `GET http://barcodes.olegon.ru/api/card/name/<штрихкод>`. Доступ платный, но дёшево: https://olegon.ru/forumdisplay.php?f=374
- **ean-db.com** — API `GET https://ean-db.com/api/v2/product/{barcode}`, есть российские товары, платно за запрос: https://ean-db.com/docs/productApi
- **barcode-list.ru** — открытый сайт-база (поиск по штрихкоду отдаёт название), можно аккуратно парсить.

### 5. Ритейлеры (парсинг с российского IP)
Сайты магазинов дают состав/КБЖУ/фото, но **штрихкод в публичном вебе показывают не все** — часто он есть только в API мобильных приложений. Подход: поставить mitmproxy, открыть приложение магазина, посмотреть JSON карточки товара — если там есть `barcode`/`ean`, писать парсер по этому API.

Кандидаты (проверять из РФ; из-за гео-блокировок я их отсюда не достал): Глобус (в вебе показывает штрихкод на карточке), Metro, ВкусВилл, Перекрёсток/Vprok, Лента, Магнит, Пятёрочка, Купер, Озон/WB (в характеристиках иногда есть штрихкод).

### 6. Краудсорсинг в приложении — обязательный слой
Неизвестный код → «сфоткай этикетку и штрихкод» → OCR/LLM разбирает состав → карточка в базу. Каждый юзер расширяет покрытие. Бонус: заливать еду обратно в OFF нельзя заставить, но можно — это улучшит и твой источник.

## Правовые заметки (важно)
- Нацкаталог по API-ключу и открытые дампы (aioke, OFF) — чисто.
- Парсинг публичных страниц ритейлеров: соблюдай разумный rate-limit, не обходи авторизацию/пейволы. Учитывай, что базы данных охраняются смежным правом (ст. 1334 ГК РФ) — «извлечение существенной части» чужой БД может быть претензией. Извлекай фактические данные о товарах (состав/КБЖУ — фактическая информация, не объект авторского права), не копируй описания/фото ритейлера дословно; фото лучше брать из Нацкаталога/OFF или от юзеров.
- OFF — ODbL (share-alike, атрибуция).

## Пайплайн

```bash
pip install duckdb requests
python3 off_import.py          # ~35к еды с составом/КБЖУ → products.db
python3 aioke_import.py        # +1.8 млн штрихкодов (не-еда)
NK_APIKEY=xxx python3 natcatalog_enrich.py   # обогащение карточками Нацкаталога (из РФ)
```

База: `products.db` (SQLite), таблица `products`:
`barcode PK, name, brand, quantity, ingredients, kcal_100g, proteins_100g, fat_100g, carbs_100g, categories, image_url, source, popularity`.

Lookup в проде: `SELECT * FROM products WHERE barcode = ?` → если пусто, каскад: Нацкаталог API → ean-db/olegon → краудсорсинг-флоу.
